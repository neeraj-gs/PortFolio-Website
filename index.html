The Edge

What Sets Me Apart

“Just add AI to the product” “Just ask ChatGPT to build it” “Let's vibe code something and ship it” “Can't we prompt our way to an app?”

Most AI work stops at the demo. Mine starts there. Prompting gets you a prototype; shipping something people depend on is a different job — twenty-five of them, in practice. This is the part most AI developers skip.

Set 01

Context & Retrieval

Getting the right facts in front of the model.

  1. 01

    Retrieval-augmented generation

    Answers grounded in your own documents, with a citation behind every claim.

  2. 02

    Vector databases

    pgvector and hybrid search, tuned until the right chunk actually ranks first.

  3. 03

    Embeddings

    Chunking and embedding strategy decided by recall tests, not by default settings.

  4. 04

    Context window management

    I budget the window: what gets in, what gets summarised, what gets dropped.

  5. 05

    Data pipelines

    OCR, parsing and enrichment that turn messy PDFs into queryable structure.

Set 02

Reasoning & Control

Making the model actually do the work.

  1. 06

    System prompt design

    Prompts written as specs, versioned in the repo and reviewed like code.

  2. 07

    Chain-of-thought prompting

    Reasoning where it pays for itself, skipped where it just burns tokens.

  3. 08

    Structured outputs

    Typed schemas at every boundary, so downstream code never has to parse prose.

  4. 09

    Tool calling

    Models that act: query the database, call the API, write the result back.

  5. 10

    Agentic workflows

    Durable multi-step runs on Temporal — resumable, retryable, never silently stuck.

  6. 11

    Memory management

    What an agent carries between runs, and what it’s required to forget.

Set 03

Quality & Evals

Proving it works before anyone depends on it.

  1. 12

    Model evals

    Golden datasets and scored runs. Nothing ships without clearing the gate.

  2. 13

    Hallucination testing

    Every figure traced back to its source page, or it never reaches the memo.

  3. 14

    A/B testing prompts

    Two variants, real traffic, one winner — measured rather than argued about.

  4. 15

    Prompt versioning

    Every prompt has a version, a diff and a rollback path.

  5. 16

    Fine-tuning

    Reached for last, once retrieval and prompting stop paying for themselves.

  6. 17

    Temperature tuning

    Deterministic where accuracy matters, loose where exploration does.

Set 04

Production & Cost

Keeping it fast, cheap and observable.

  1. 18

    LLM observability

    Full traces in Langfuse: every call, its cost, its latency, its output.

  2. 19

    Token cost tracking

    Cost per run is a product metric I watch as closely as conversion.

  3. 20

    Latency budgets

    A time budget per step, with streaming and caching to stay inside it.

  4. 21

    Rate limit handling

    Backoff, queueing and failover, so a provider blip isn’t an outage.

  5. 22

    Model selection

    Routed per task through LiteLLM — the cheapest model that clears the bar.

Set 05

Safety & Trust

The part every enterprise asks about first.

  1. 23

    Guardrails

    Validation on the way in and on the way out. Agents get permissions, not free rein.

  2. 24

    Red teaming

    I try to break my own agents before a customer finds the way in.

  3. 25

    Security reviews

    Multi-tenant isolation, SSO and EU data residency, designed in from day one.
